Distractor tells

An option carrying one of these is usually wrong. They recur across every published scenario.

  • A trained classifier or routing layer, where a better prompt has not been tried
  • Sentiment analysis as a proxy for case complexity
  • The model's own self-reported confidence score as a gate
  • A larger model or bigger context window to fix attention quality
  • Pushing the burden onto developers or humans instead of the system
  • Prompt instructions where the requirement is deterministic
  • Speculative caching of things you cannot predict
  • Consensus voting across repeated runs, which suppresses real findings

API surface that does not exist

Invented flags and files appear as distractors. Knowing the real surface cold is worth more here than any amount of reasoning.
